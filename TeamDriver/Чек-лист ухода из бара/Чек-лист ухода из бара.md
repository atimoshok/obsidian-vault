Чек-лист ухода из бара - это напоминалка, которую повесим на стену в баре (+ возможен простенький дизайн)

- [ ] Оставь за собой чистый стол (убери посуду, протри поверхность)
- [ ] Собери весь мусор (в помещении и снаружи)
- [ ] Вынеси его (в бак на внутреннем дворе)
- [ ] Затуши мангал
- [ ] Занеси внутрь всё, что выносили из бара
- [ ] Промой пивную систему - если пользовались кегой + инструкция по промывке (не откладывать на несколько дней во избежание образования плесени)
- [ ] Зимой: Выключи отопление (тепловая панель + тепловая пушка)
- [ ] Выключи свет (выключатель в баре + электричество в щитке)
- [ ] Плотно захлопни дверь
